01 / Concepto

Que es Docker en la practica

Docker empaqueta tu aplicacion y todo lo que necesita para ejecutarse (lenguaje, librerias, archivos de configuracion) en una imagen inmutable. Luego esa imagen se ejecuta como un contenedor: un proceso aislado del resto del sistema, con su propio sistema de archivos y su red.

Maquina virtual

Emula hardware completo y arranca un sistema operativo entero.

  • Arranque de minutos
  • GB de RAM por instancia
  • Aislamiento fuerte
Elegido por {{ site_name }}

Contenedor

Comparte el kernel del host y aisla solo el proceso de tu app.

  • Arranque en segundos
  • Decenas de MB de RAM
  • Aislamiento a nivel de proceso
